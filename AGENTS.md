# This is NOT the Next.js you know

This version has breaking changes — APIs, conventions, and file structure may all differ from your training data. Read the relevant guide in `node_modules/next/dist/docs/` before writing any code. Heed deprecation notices.

# UI Components and Theming

You MUST use `shadcn/ui` for all interface elements. Adhere strictly to its component structures, conventions, and theming system. Rely on its utility classes and design tokens rather than writing custom Tailwind CSS from scratch whenever possible.
